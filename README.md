Projeto de Prática Profissional em ADS
CLRM Scout – Sistema de Estatísticas de Futebol

Sistema web desenvolvido para registro de eventos de partidas de futebol e geração de estatísticas e rankings de jogadores.

Funcionalidades
- Registro de Eventos
  - Cadastro de gols;
  - Cadastro de assistências;
  - Cadastro de cartões amarelos;
  - Cadastro de cartões vermelhos;
  - Validação do minuto do evento (0 a 140);
  - Validação da consistência entre jogador e partida;
  - Tratamento de transferência de jogadores entre equipes.
- Estatísticas
  - Consulta de estatísticas de jogadores;
  - Estatísticas totais;
  - Estatísticas por equipe;
  - Histórico de partidas;
  - Filtros por campeonato;
  - Filtros por time.
- Rankings
  - Ranking de artilharia;
  - Ranking de assistências;
  - Ranking disciplinar;
  - Ordenação disciplinar por:
    - Cartões vermelhos;
    - Cartões amarelos.

Como Executar o Projeto

1. Clonar o repositório
git clone https://github.com/CauePaganeli/PPADS---CLRM-Scout.git
2. Acessar a pasta do projeto
cd PPADS---CLRM-Scout
3. Instalar as dependências
npm install
4. Executar a aplicação
npm start
5. Acessar no navegador
http://localhost:3000
